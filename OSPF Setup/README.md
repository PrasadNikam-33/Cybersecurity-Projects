OSPF (Open Shortest Path First) Setup

📌 Overview

This project demonstrates the configuration of the Open Shortest Path First (OSPF) dynamic routing protocol in a network using Cisco Packet Tracer. OSPF enables routers to discover network routes dynamically and select efficient paths for packet transmission using Dijkstra’s Shortest Path First (SPF) algorithm.

🎯 Objectives

Understand the fundamentals of the OSPF routing protocol.

Configure IP addresses on PCs, routers, and a server.

Enable OSPF on multiple routers using CLI commands.

Establish communication between different networks.

Verify connectivity through packet transmission.

🛠️ Requirements

Cisco Packet Tracer

3 Routers

PCs and a Server

Serial DCE/DTE connections

Appropriate IP addressing and subnet configuration

🧪 Testing

After configuring OSPF on all routers:

Check the routing tables to verify learned routes.

Use the show ip ospf neighbor command to check OSPF neighbor relationships.

Use the ping command to test connectivity between devices on different networks.

Verify successful packet transmission across the network.

📚 Key Learnings

Dynamic routing and link-state routing concepts.

OSPF configuration using Cisco IOS CLI.

Network addresses and wildcard masks.

Route discovery and dynamic path selection.

Connectivity verification and troubleshooting.

✅ Conclusion

This practical demonstrates how OSPF enables dynamic communication between multiple networks. It provides hands-on experience with router configuration, route discovery, and connectivity testing while highlighting OSPF's efficiency, scalability, and adaptability to network changes.
