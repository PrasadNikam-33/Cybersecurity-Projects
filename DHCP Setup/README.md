# 🌐 DHCP Setup<br>

This project demonstrates the configuration and working of **Dynamic Host Configuration Protocol (DHCP)** using **Cisco Packet Tracer**.<br><br>

## 📌 Overview<br>

DHCP automatically assigns network configuration details such as IP addresses, subnet masks, default gateways, and DNS server addresses to devices on a network.<br>

In this setup, a **router** acts as the default gateway, while a **server** is configured as the DHCP server to automatically assign IP addresses to connected PCs.<br><br>

## 🛠️ Network Components<br>

- Router – Acts as the default gateway<br>
- Switch – Connects devices within the network<br>
- Server – Configured as the DHCP server<br>
- PCs – Receive IP configuration automatically<br><br>

## ⚙️ Configuration<br>

The setup involves:<br>

1. Connecting the router, switch, server, and PCs.<br>
2. Assigning an IP address to the router.<br>
3. Assigning a static IP address to the DHCP server.<br>
4. Enabling and configuring the DHCP service on the server.<br>
5. Setting the default gateway and starting IP address range.<br>
6. Configuring PCs to obtain their IP addresses automatically using DHCP.<br>
7. Verifying that the PCs receive valid network configurations.<br><br>

## 🎯 Objective<br>

To understand how DHCP works and demonstrate how a DHCP server automatically provides IP addressing information to devices within a network.<br><br>
