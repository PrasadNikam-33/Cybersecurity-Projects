# 🔐 Telnet & SSH Configuration in Cisco Packet Tracer<br>

This project demonstrates the configuration and testing of **Telnet and SSH (Secure Shell)** for remote access to a Cisco router using **Cisco Packet Tracer**.<br><br>

## 📌 Overview<br>

The objective of this project is to understand how network devices can be remotely accessed and managed using Telnet and SSH.<br>

The report covers:<br>

* 🌐 Creating a basic **PC–Router network**<br>
* ⚙️ Configuring IP addresses and interfaces<br>
* 🔑 Setting router and remote-access passwords<br>
* 🖥️ Configuring **VTY lines**<br>
* 📡 Establishing remote access using **Telnet**<br>
* 🔐 Configuring **SSH with username/password authentication**<br>
* 🔑 Generating **RSA encryption keys**<br>
* 🛡️ Enabling **SSH Version 2**<br>
* 🔍 Understanding the security differences between Telnet and SSH<br><br>

## 🛠️ Tools Used<br>

* **Cisco Packet Tracer**<br>
* **Cisco IOS CLI**<br>
* **Command Prompt / Terminal**<br><br>

## 🔎 Telnet vs SSH<br>

**Telnet** provides basic remote command-line access but transmits information without encryption, making it insecure for sensitive communication.<br>

**SSH** provides encrypted remote access and authentication, making it the preferred protocol for securely managing network devices.<br><br>

## 🎯 Key Learning<br>

This project provided practical experience in configuring remote access to network devices and demonstrated why **SSH is preferred over Telnet in modern networks**, especially from a cybersecurity perspective.<br><br>

## 📄 Project Report<br>

The complete report contains the step-by-step configuration process, Cisco IOS commands, screenshots, and explanations for both **Telnet and SSH setup**.<br><br>
