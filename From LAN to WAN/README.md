# 🌐 LAN to WAN – Cisco Packet Tracer <br>

A hands-on networking project demonstrating how to build a **LAN from scratch** and expand it into a **WAN** by connecting two separate LANs using routers and static routing.<br><br>

## 📌 What This Project Covers<br>

- 🖥️ Creating a LAN using PCs and switches<br>
- 🌐 Configuring IP addresses, subnet masks & gateways<br>
- 🔀 Configuring routers using Cisco IOS CLI<br>
- 🔗 Connecting two separate LANs<br>
- 🛣️ Configuring static routing<br>
- 📡 Testing communication between different networks<br><br>

## 🛠️ Tool Used<br>

- **Cisco Packet Tracer**<br>

## 📚 Key Concepts<br>

`IP Addressing` • `Subnetting` • `Switching` • `Routing` • `Static Routing` • `ICMP` • `Network Communication`<br><br>

## 📄 Project Write-up<br>

The detailed write-up contains the **step-by-step implementation**, Cisco CLI configurations, network topology, and connectivity testing.<br><br>

## 🎯 Learning Outcome<br>

This project strengthened my practical understanding of **network architecture, routing, and communication between different networks**, providing a foundation for further learning in **Cybersecurity and Ethical Hacking**.<br><br>
